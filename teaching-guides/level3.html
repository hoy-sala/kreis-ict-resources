ICT Level 3 - Teaching Guide

Classes: 8, 9, 10 | Duration: June - January (8 months) | Period: 40 minutes

Note: Same textbook used across Classes 8, 9, 10. Pedagogical approach varies by class level.

1. Curriculum Overview

ICT Level 3 covers advanced topics in programming, data structures, and computational thinking. The same textbook is used for Classes 8-10, with differentiated instruction based on student level.

Themes Covered

6Emerging Technologies12AI basics, IoT concepts, Cloud computing introduction

5. Resources Required

Hardware

  • Computer lab with 1 PC per 2 students (minimum)
  • Internet connection (2 Mbps minimum)
  • Projector for demonstrations
  • Speakers and headphones

Software (Free/Open Source)

  • Operating System: Ubuntu Linux or Windows
  • Office Suite: LibreOffice / Google Workspace
  • Programming: Scratch, Python (IDLE)
  • Database: LibreOffice Base
  • Web Design: VS Code / Notepad++, Firefox
  • Browser: Firefox / Chromium

6. Dormitory Tasks (Zero Lab Access)

For residential schools with limited lab time, these paper-and-pencil tasks can be assigned for supervised evening study:

  • Python Code Tracing: Trace programs on paper, predict outputs
  • Flowchart Design: Create flowcharts for algorithms
  • Pseudocode Writing: Write algorithms in pseudocode
  • Database Query Practice: Write SQL queries on paper
  • HTML Markup: Write HTML code on paper
  • Binary/Hex Conversions: Practice number system conversions

7. Capstone Projects

Project 1: School Library Database

Integration: Library Science + ICT

Description: Students create a database to manage library books with search, add, and delete functionality.

Skills: Database design, SQL queries, CRUD operations

Project 2: Weather Data Analysis

Integration: Science + ICT

Description: Students analyze weather data using spreadsheets, create charts, and write a report.

Skills: Data analysis, chart creation, report writing
